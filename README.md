## 🧗 La Grimpe : live TikTok interactif

Overlay de live TikTok où une mascotte escalade une tour grâce aux taps et aux cadeaux des spectateurs (classement, mini-jeux, soundboard, régie sur tablette).

👉 Tout est dans le dossier [`la-grimpe/`](la-grimpe/README.md) : installation, lancement et réglages.
